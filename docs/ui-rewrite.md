## 页面任务与结构

主任务是选择资料库、浏览和筛选媒体、核对详情，再执行刮削或整理。
媒体占据主区域，库导航在左侧；资料库名称和路径与操作分成一组，搜索、筛选与视图切换为第二组。
窄窗口展开详情后操作区自然换行，保留标题可读性。设置从长滚动页面改成五个分类标签页。

## 实现

- 基础组件使用官方 shadcn/ui `new-york-v4` 注册表源码，存放在 `desktop/src/components/ui`，保留 MIT 许可。配置入口 `desktop/components.json`，`@/` 路径别名同时接入 TypeScript 和 Vite。
- Button、Input、Checkbox、Switch、Select、NativeSelect、Tabs、Dialog、AlertDialog、DropdownMenu、Badge、Progress、Table 覆盖媒体页、设置、清理/删除/匹配、日志、目录浏览与批量重命名。原生窗口控件、系统文件选择器继续使用 Tauri。
- 媒体工具栏与任务面板独立为 `LibraryToolbar`、`TasksDock`。任务进度采用具备数值语义的 Progress。
- 右键及普通菜单改为 Radix 菜单，支持键盘导航、Escape 关闭及边缘定位。剧集分季使用 Tabs，保留封面、集数及分季菜单。
- 删除、清理、匹配对话框使用 Dialog 的 Portal、焦点约束和 Escape 关闭；统一 `ModalFrame` 处理 Motion 入场及关闭后焦点恢复。
- 两处 `window.confirm` 改成统一 AlertDialog，默认焦点在取消按钮；未确认不会执行删除库命令。重复请求取消旧请求，避免悬挂 Promise。
- Motion 用于弹窗、设置页面入场、任务面板进出和提示消息。根部 `MotionConfig reducedMotion="user"`；CSS 动画也响应减少动态效果。未对大量媒体卡片逐项添加入场动画。
- 导航和工具栏统一 Lucide 图标。保留原有主题与强调色选择，补充深色主题中的亮强调色，避免选中标签对比度不足。
- 删除被替代的旧按钮、输入框、选择器、开关及菜单 CSS。领域布局仍由软件自己的 CSS 维护，不重新引入外部设计 token 仓库或生成管线。

组件依据：[shadcn 手动接入](https://ui.shadcn.com/docs/installation/manual)。动效依据：[Motion 无障碍指南](https://motion.dev/docs/react-accessibility)。依赖实际版本写入 pnpm lockfile。

## 字体一致性修正

恢复项目原有文字层级：页面标题 24px/32px、分区与弹窗标题 18px/24px、正文及操作控件 14px/20px、辅助说明 12px/16px 或 12px/18px。移除输入框 13px 特例及响应式字号变化；紧凑按钮只改变尺寸，不降低字号；资料库、设置、重命名页共用标题规则。

在 1280×720 中文组件预览中检查真实 LibraryToolbar、输入框、按钮、选择器、Tabs 和 Dialog，并读取计算样式确认字号与行高。该检查覆盖组件排版，不代表完整原生页面验收。TypeScript 检查通过。

## 视觉精修

保留现有字号层级。侧栏采用次级表面，当前资料库用明度和细边界标识；资料库页头与内容共享底色、左右对齐线，工具栏按钮统一 36px 高。海报列间距改为 16px，行间留白同步调整虚拟列表计算，标题与海报左对齐。控件使用 8px 圆角，弹出菜单 10px；输入控件去掉常驻阴影，悬浮菜单保留层次。设置行内边距增加，修正主题预览卡被按钮横向布局挤压的问题。
